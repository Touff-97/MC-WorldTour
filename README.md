# MC-WorldTour
A Minecraft mod to explore a world through an automated tour -using minecarts- and seamless transitions between world "snapshots"

## What steps are needed to complete this mod?

1. Define and store paths the mod should go through one at a time with a defined speed.
2. Define transition points where the paths change and potentially the world being shown is changed for the next on the queue.
3. The variable speed of the cart should allow a player to get into the ride and enjoy the details without ever getting off (lower speed when at landmark locations = more time to appreciate, higher speeds during empty or transition periods)
4. The cart should let a player get off the ride, pause and continue after the player is done exploring the current area.
5. Possibly provide voice-over at times to explain certain features of the world or mix stories and anecdotes in.
